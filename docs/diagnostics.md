# 検証範囲と実再生記録

2026-09-08時点。公開できる項目だけを実験記録から要約しています。作品・アカウント・ホスト名・生の通信やトレースは含めていません。

## v0.4.0の確認範囲

通常フルHDモードとツールバーUIを追加しました。以下は実サービスの再生成功とは分けて扱います。

- オフラインテスト28実行・19ファイル。新モードに75秒/30秒の停止タイマーがないこと、モック時刻を2時間進めても時間を理由に停止しないこと、複数のSDK作成・再生POST・master取得・native鍵要求/更新を通すことを検査。
- 既存の厳密なFHD/SDR候補選択と失敗時の中止を維持。native更新失敗は元のエラーを伝播し、保存モードをOFFへ戻すことを検査。旧診断モードの回数制限と予定停止も回帰テスト。
- ツールバーのクリック・右クリックのハンドラーをモックAPIで検査。Disney+以外のURL、別フレーム/送信者、過大な状態通知、連打、操作途中の別サイトへの移動で対象外の操作を行わないことを検査。
- Playwrightの専用プロファイルで拡張を読み込んだChromiumを使用。全通信を人工ページに置き換え、実サイト、認証情報、SDK、CDMは使用せず、通常時パネルなし、デバッグ表示/非表示、ページ側の切替操作と再読み込み後のON/OFF・HD/OFFバッジを確認。
- Edgeのネイティブなアイコン・右クリックメニュー操作そのものと、v0.4.0での長時間・作品全編・鍵切替・シーク・吹替変更の実再生は未確認。旧版の実再生結果を新モードの実証として使わない。

通常モードでも、対応SDKや候補を確認できない場合、DRM/映像エラー、ガード不成立では停止します。拡張が自動再試行する機能はありません。別作品・広告・サービスのSDK更新などで条件が変わる場合もあり、「止まらない」ことを保証するものではありません。

## 短時間1080p SDRの成功

- 実再生を確認した版: **v0.3.13**。後続のv0.3.16/v0.4.0の新規実機テストではありません。
- ブラウザー: 記録上 **Edge Beta** の既存プロファイル。Stable版の成功確認として扱いません。
- モード: `1080p-hevc-single-sdr`。非HDR要求、1920×1080・SDR・HEVC/AAC候補を1本に固定。
- 同じテストで再試行・シーク・音声変更なし。masterは27候補中2候補が適合し、1候補を保持。
- 接続CDM: `com.microsoft.playready.recommendation.3000`、persistent-license、hardware-secure codecs有効。API能力照会だけでなく、動画に接続したCDMの記録で確認。

最初の保存サンプルからメディア時刻は68.93秒、フレームは1666枚増加。ネイティブ側の成功サンプル処理期間も約70.6秒でした。**約70秒の1080p実再生**の証拠であり、時間の絶対値90.71秒は今回の再生継続時間ではありません。

SDK開始から75秒のwatchdogで意図的に終了し、この比較では追加のライセンス要求・メディアエラーを観測しませんでした。古いUIは予定停止を再生エラーに分類していましたが、後続版で予定停止の表示を分離しています。

Media Internalsの記録:

- MediaFoundationRenderer、HEVC Main 10、coded/natural/visibleの各寸法1920×1080。
- BT709、LIMITED、HDR metadataなし。**Main 10だからHDRという意味ではありません**。
- AAC、2ch stereo、48kHz。複数吹替を同時処理していたという証拠はこの比較にありません。

作品全編、2回目の鍵切替、保存したセッションの再ロード、別作品・別GPUでの安定性は未確認です。

## 4Kについて

HDR要求で3840×2160のmanifest候補やライセンス処理の進行は観測しましたが、4Kの実フレーム進行は確認できていません。記録したHDR masterの通常4K候補はPQで、SDR 4K候補はありませんでした。これは全作品・全アカウントの配信仕様を示すものではありません。

ハードウェアPlayReady / 4K HDRの実験でPCフリーズ・BSODが複数回発生しました。GPU・ドライバー・Windows・保護出力経路などの関与は未確定です。「AMD全体で再生不可能」「NVIDIAなら成功」「8 bpcなら安全」とは結論していません。

外部の類似報告と修正履歴は[関連報告・修正情報](related-issues.md)に分離しています。原典で確認できた範囲と、共有された二次情報を区別しており、本節の実機観測を外部チケットの再現・修正確認として扱いません。

## 診断表示の読み方

1. **manifest候補**: サーバーから列挙された宣言。選択・復号・表示の証拠ではありません。I-frame専用候補と通常候補も区別します。
2. **EME API受付 / keys-usable**: 能力照会や鍵状態。映像が動いたという意味ではありません。
3. **接続CDM**: 動画に付いたMediaKeysから追跡した状態。GPUドライバーの正しさまで証明しません。
4. **寸法 + 時間 + フレーム進行**: 短時間の実再生を判断する材料。5秒の4K判定が仮に成立しても、作品全編の安定性を保証しません。
5. **予定停止とエラー**: `time-limit-75s`などのガード停止と、復号・ライセンス・サイト側のエラーを分けて記録します。

## v0.3.16の境界

- 1080p単一候補の75秒比較、SDR候補だけのmanifest診断、SDK/EMEの各種比較を含みます。
- 4K HDR単一候補モードはSDK開始から30秒、または追加のnative鍵要求の前で停止する設計です。**初回のCDM処理でOSが停止する危険は残ります**。
- SDK連携は調査対象の `26.10.0-jasmine` に限定されています。未知の版・構造や必要なガードが成立しない場合、該当する比較を中止します。
- 公開のための変更は名前・MITメタデータ・配布構成・文書・テスト実行環境です。オリジナルv0.3.16の再生アルゴリズム、モード、タイマーは変更していません。
